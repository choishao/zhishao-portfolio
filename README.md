# ZHISHAOCUI — Designer Portfolio

个人设计师作品集官网。

## 功能
- 黑白极简设计风格
- CRT 启动动画
- 作品展示（5个分类：平面设计/品牌/电商/AIGC/包装）
- 关于我（个人介绍+工作经历+项目经历）
- 客户名单（支持上传Logo）
- 内容管理后台（访问 #/admin 可编辑所有文字）

## 技术栈
- 纯 HTML/CSS/JS 单文件
- Impact 展示字体
- GitHub Pages 部署

## 后台管理
访问网站后在 URL 后加 `#/admin` 进入内容管理后台，可编辑所有文字内容、作品列表、工作经历等。

## 部署
启用 GitHub Pages，选择 main 分支根目录即可。
